# 美食旅游 🍜✈️

一个基于 **uni-app** 开发的「美食 + 旅游」综合移动应用，纯前端实现，采用大众点评风格的橙色主题，集美食推荐、景点浏览、酒店预订、路线规划、购物车、订单、优惠券等功能于一体。

> 本项目为课程大作业（移动应用开发），使用 Mock 数据模拟真实业务，无需后端即可运行体验。

---

## ✨ 功能特性

- 🏠 **首页**：轮播图、8 大分类导航、美食/景点推荐列表
- 🔍 **搜索**：关键词搜索、搜索历史、热门搜索推荐
- 🗂️ **分类浏览**：美食 / 景点 / 酒店 / 休闲 / 火锅 / 小吃 / 特产 / 路线
- 📄 **详情页**：商品/景点详情、标签、用户评价
- ⭐ **收藏**：收藏/取消收藏，本地持久化
- 👣 **足迹**：自动记录浏览历史，支持清空
- 💬 **评价系统**：写评价、查看我的评价
- 🛒 **购物车**：加购、改数量、结算
- 📦 **订单**：订单列表、状态管理
- 🎟️ **优惠券**：领取/使用优惠券
- 👤 **个人中心**：登录、个人资料、收货地址管理
- ⚙️ **更多**：设置、客服中心、关于我们
- 🚀 **引导页**：首次启动展示引导

所有用户数据（收藏、购物车、订单、搜索历史等）均通过 `uni.setStorageSync` 存储在本地。

## 📦 数据说明

所有业务数据集中在 [common/mock.js](common/mock.js)，导出以下模块：

| 模块 | 说明 |
|------|------|
| `banners` | 首页轮播图 |
| `homeCategories` | 首页 8 大分类 |
| `foodList` | 美食列表（含评价） |
| `travelList` | 景点列表（含开放时间、评价） |
| `hotelList` | 酒店列表 |
| `leisureList` | 休闲娱乐 |
| `specialtyList` | 特产 |
| `routeList` | 旅游路线 |
| `orderList` | 订单数据 |
| `couponList` | 优惠券 |
| `defaultUserInfo` | 默认用户信息 |

> 项目内的商品/景点图片部分使用 `https://picsum.photos` 占位图，部分使用本地 `static/images` 资源。

## 🚀 快速开始

### 运行环境

- [HBuilderX](https://www.dcloud.io/hbuilderx.html)（推荐，uni-app 官方 IDE）

### 导入项目

1. 克隆或下载本仓库到本地
2. 打开 HBuilderX → **文件** → **导入** → **从本地目录导入** → 选择项目根目录

### 运行到浏览器（H5）

HBuilderX 菜单栏 → **运行** → **运行到浏览器** → 选择 Chrome 即可预览。

### 运行到微信小程序

1. 在 `manifest.json` → 「微信小程序配置」中填入你自己的小程序 `appid`
2. 菜单栏 → **运行** → **运行到小程序模拟器** → **微信开发者工具**

### 运行到手机（App）

菜单栏 → **运行** → **运行到手机或模拟器**（需连接真机或配置 Android/iOS 模拟器）。
