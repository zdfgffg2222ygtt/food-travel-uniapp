# 美食旅游

移动应用开发课程的大作业，用 uni-app 写的一个美食 + 旅游的 App。没接后端，数据全是 mock 的，直接用 HBuilderX 打开就能跑。

## 功能

- 首页：轮播图、分类导航、推荐列表
- 搜索：关键词搜索、搜索历史、热门搜索
- 分类：美食 / 景点 / 酒店 / 休闲 / 火锅 / 小吃 / 特产 / 路线
- 详情页：介绍 + 标签 + 用户评价
- 收藏、足迹（浏览历史）
- 写评价、我的评价
- 购物车、订单、收货地址
- 优惠券
- 登录、个人资料
- 设置、客服中心、关于我们
- 首次启动有引导页

用户数据（收藏、购物车、订单、搜索历史这些）都存在本地 storage 里，没接后端。

## 运行

1. 用 HBuilderX 导入项目：文件 -> 导入 -> 从本地目录导入
2. 运行到浏览器：运行 -> 运行到浏览器 -> Chrome
3. 要跑微信小程序的话，先去 manifest.json 里填自己的小程序 appid，再运行到微信开发者工具

## 目录结构

```
├── App.vue           # 入口，全局样式
├── main.js           # 挂载 Vue
├── manifest.json     # 应用配置
├── pages.json        # 路由和 tabbar 配置
├── common/mock.js    # 全部 mock 数据
├── pages/            # 页面，一个文件夹一个页面
└── static/           # 图片和 tabbar 图标
```
